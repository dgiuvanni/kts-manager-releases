# КТС Менеджер — выпуски

Здесь публикуются установщики программы «КТС Менеджер». Исходного кода в этом репозитории нет.

Установленная программа сама проверяет этот репозиторий и сообщает администратору о новой версии.

**Как обновить:** скачайте `KTSManagerSetup.exe` из последнего выпуска ([Releases](../../releases/latest)) и запустите его на компьютере, где установлена программа. Данные, пользователи и лицензия сохраняются.
